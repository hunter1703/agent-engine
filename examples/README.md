# Examples (Mirrors Repo Layout)

This folder mirrors the top-level repo structure so you can see where to place
extensions.

## Layout

- `examples/agents/` → custom agents and tools
- `examples/cli/` → CLI/runtime commands
- `examples/engine/context/` → custom context managers
- `examples/engine/state/` → custom state stores

## Custom Agent

- `examples/agents/echo_agent/` shows a custom builder, config, and tool.

## CLI Commands

- `examples/cli/runtime/commands/example.py` shows a `/example` command.

## Context Managers

- `examples/engine/context/prefix_context.py` shows a custom context strategy.

## State Stores

- `examples/engine/state/example_store.py` shows a custom state store.
